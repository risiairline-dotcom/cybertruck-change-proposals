## 固定主线与可替换部分

主线为已验证路线粗停→停车证据→固定观察姿态→新帧识别→工作窗口判断→必要且已验收的局部修正→绑定机械动作→结果确认→账本提交。

固定部分：唯一相机服务、唯一串口核心、原始采集身份、有效帧龄、观察姿态绑定、UNKNOWN、任务码锁存、动作与视觉结果分离、证据可追溯。

可替换部分：候选区域内的圆心估计、颜色分类、QR解码后备、离线几何标定。替换只改变明确的算法适用范围，不授予运动权限。按任务阶段启用模式，不要求四路同时运行。任务调度与设备反馈线程不执行耗时图像算法或落盘。

不把“图像居中”当作统一任务目标。原料抓取、粗加工放置、再取、第一层放置、第二层码垛各自定义有效工作窗口，关联真实成功样本、载荷、平面与姿态。未知窗口保持未知，不由视觉死区推导可抓范围。

以下是待实现或对接的语义字段，不能假定现有模块已全部提供。优先适配已有等价字段，避免重复建立身份体系。

| 配置 | 源码提交、算法名/版本、profile SHA、相机模式、曝光/白平衡已知状态、裁剪/缩放/去畸变映射版本 |
| 场景 | 工位、目标类别与编号、目标平面/高度、光照类别、载荷、完整观察姿态摘要及稳定证据 |
| 执行关联 | 只在真实集成中绑定run/action、boot/session、零点版本、停车/姿态代次；离线不得伪造为真实会话 |

| 度量输出 | metric_valid、标定版本、适用区域、毫米位置及验证误差；无有效标定则毫米值为空 |

任何坐标必须明确raw_pixels、undistorted_pixels、ROI_pixels或plane_mm；ROI回全图的变换只做一次，处理像素与源像素不能混用。H输入必须与拟合时的像素域一致，不能对原图点使用去畸变H。

帧龄从原始采集来源计算，保留已建立的传输及处理计龄逻辑，跨时钟域使用项目既有协议，不直接相减不同设备单调时钟。后备解码、缓存、平滑不刷新采集时间。停稳或姿态改变后先建立新观察代次，再累积新帧；旧帧和预测帧不算有效确认。

算法质量不是物理许可。最终Task事件沿用整机合同：MOTION_DONE不等于CONFIRMED；重复视觉帧不重复计数；未检测到不等于空爪；命令返回不能证明夹持或释放。

## V1 离线评估与诊断

允许离线先行，依赖V0样本清单。保留原tools/replay_vision.py的迁移一致性用途，新增独立候选评估入口，例如tools/evaluate_vision_candidates.py；文件名是建议，实际以源码约定为准。

候选运行器必须支持旧/新算法同输入、显式版本和输出目录、按场景汇总、失败不丢记录；不打开相机/串口、不调用实时控制、不改用户profile。原始诊断记录应包含候选数、接受/拒绝、原因、误差与时延。

| 指标 | 统计方式 |
| --- | --- |
| 颜色/环号/QR正确性 | 正确、错误接受、漏检、UNKNOWN分别列分子分母与混淆矩阵 |
| 中心准确性 | 仅独立真值样本：X/Y有符号偏差、欧氏误差P50/P95/max及样本数 |
| 重复性 | 固定场景不同帧及独立回位分别统计；不能混成一个标准差 |
| 覆盖性 | 有效输出/全部预期可见目标，按场景分层；禁止全拒绝换高正确率 |
| 处理性能 | 预热条件、每模式P50/P95/max、样本规模、异常；PC仅供相对比较 |
| 端到端性能 | 仅实测：采集到有效输出帧龄、超时/拒绝、吞吐、CPU/温度、并发负载 |

首版测试至少覆盖空白、完整环、多环、局部遮挡、图像裁切、椭圆、邻环串层、无效半径、NaN/Inf、重复帧、过期帧、姿态改变。测试应检验结果语义和错误拒绝，不能仅验证内部函数被调用。

退出条件：输入可复现，真值/重复性/性能区分，独立集不能被调参污染。没有真值时明确限制而不输出伪毫米精度。

## V2 机构与相机几何诊断

离线先准备表格、计算和采样指导；物理测量由恢复授权后的现场负责人组织。机械与相机诊断可以并行，不预承诺一天完成。

### 机构重复性和落点

固定同一人工零点、相同观察/作业姿态，空载/载料各至少10次作为初筛目标，另测正反方向接近。每次记录目标、实际反馈、独立物理测量、相机姿态、载荷、供电条件和异常。10次不是可靠率证明，钢尺只用于与其分辨能力匹配的粗测；需要亚毫米结论时使用足够分辨率、可固定基准的量测方法并评估不确定度。

分开测返回观察位、末端目标位和释放退出后的物料落点；不重新手摆物料掩盖累计偏移。相同偏差的均值、重复散布、负载变化、方向相关差异分别报告。量具分辨不出目标预算时，结论为测量不足，不是误差为0。

### 内参与去畸变

先确认相机编号、分辨率、裁剪、焦距/对焦是否稳定。标定板实际尺寸、平整度、视场覆盖、不同倾角均记录；不把同一姿态连拍当充分姿态覆盖。训练图之外保留独立检查图，评价不同视场位置误差，不只看训练重投影均方根。

去畸变作为可关闭候选。可预计算映射降低重复计算成本；效果与耗时在同输入比较。若使用新的相机矩阵、ROI或裁剪，应保存完整变换、有效域及映射版本。改变像素域后重新验证中心目标、H、运动模型及所有像素阈值，不复用旧绑定。

### 平面尺度与H

每个工位/目标平面/观察姿态分别建立映射，至少4个非退化拟合点加独立检查点，建议更多且覆盖有效区域。网格纸可用于初筛，需实测格距、平整、固定以及标注误差。检查点不参与拟合；重复重新摆板和回观察位后检查映射稳定性。

H输出像素对应平面毫米，不解决执行指令的方向与位移。ground、物料顶面和堆叠顶面不默认共用。不得将workspace中的metric_valid/applied直接翻True；设计校验、适用域、版本、失效和验收记录，实际接入由集成阶段完成。

退出条件：误差来源初步分类并记录测量能力，选择首要问题。若执行或机构误差占主导，视觉候选可继续离线，但不靠更小像素死区解决实物不稳定。

## V3 圆环定位候选

依赖V1及明确的圆心/识别失败样本；不要求先完成全部V2。保留原fitEllipse、环层筛选、覆盖率、编号与裁切信息。首版只做可信单层候选的ROI精修，不重写整个RingDetector。

必须先明确当前候选提供的r0、轴长、角度和图像尺度。dr根据本尺度下层间距、粗中心不确定度和透视变化确定；40%只能作为候选经验值，不是通用保证。若不确定度与层间距不兼容，应拒绝精修而非扩大搜索带猜层。

修正评审指出的边界索引、平滑方向和诊断输出问题，记录有效射线分布，避免图外值和暗背景充当环。对于明显椭圆/斜视，比较原椭圆拟合、适配椭圆的精修或经验证平面矫正；不得仅凭二倍角拟合残差宣称物理圆心准确。

返回结构至少包括status/reason、粗中心/精修中心、坐标域、修正量、覆盖率、残差、层选择及适用范围。无效输入受控拒绝，异常被评估器捕获并单列。算法失败不改变底盘状态。

验收必须同时报告真值误差、输出覆盖率、错误接受、不同场景及处理耗时。完整合成圆上的0.02px仅作为算法行为记录，不能作为验收目标。候选在独立集的主要目标上有收益，并不造成不可解释的新错误接受；无收益保留旧算法，保存负面结果。

## V4 颜色分类候选

仅在错误色/蓝浅蓝歧义是已复现瓶颈时执行，不作为D4必做项。先核对当前profile的样本语义，保留原始独立采样而不是把少量代表点当大量独立像素。

比较当前Lab/HSV、对角模型和完整协方差模型；QDA按d²+ln|Σ|-2lnπ比较。类别先验来源写明，协方差的正则化/收缩方法由开发集决定，检查有限性、正定性和数值稳定。优先稳定求解而非裸求逆；不为使用Ledoit–Wolf强制在Pi增加完整训练依赖，训练可离线、部署只带版本化参数。

必须保留空背景和UNKNOWN，分别标定绝对似然/距离及竞争类别间隔，不能仅取最小值强制分色。训练/开发/验收按拍摄会话分组，蓝浅蓝、黑与阴影、过曝区域重点分层。反光信息丢失时允许拒绝。

补光/偏振实验另作配对数据：同姿态、曝光策略可追溯、各颜色及空背景都覆盖，比较有无附件和不同角度，记录亮度、模糊及帧率。是否符合比赛规则需核对实际文件和安装形式，本文不授权增加场地标记。光学条件变化后重验颜色profile及几何绑定。

退出条件：独立集混淆矩阵、拒识和覆盖率有明确收益，默认旧profile可回滚；无证据不替换。

## V5 二维码候选

仅在真实解码失败成为瓶颈时执行，不因TaskLatch完善就认定解码器必然弱。先分类读取失败和观测过期。

默认原解码器；后备候选在同一原始帧和剩余阶段期限内运行，必要时只在扫码阶段启用。保留TaskLatch的去重、冲突拒绝、格式检查、新鲜帧和锁存，不允许两个解码器对同一帧贡献两次确认。跨后备运行时间仍以原采集时刻算龄，已经过期立即拒绝。

初赛只选一个有独立收益的后备实现。WeChatQRCode需模型文件及来源/SHA、兼容的contrib构建；pyzbar等需相应本机依赖。先隔离环境验证，不能直接在当前Pi运行环境覆盖多个提供cv2的包。输出形状/空结果/异常适配均测试。

测试合法/非法/冲突、重复帧、stream变化、慢解码、异常、已有锁存及无二维码。报告整个任务字符串正确率和错误接受，不能只统计“读出一些字符”。退出条件包含目标Pi真实时效，PC快不算通过。

## V6 集成与物理验收

依赖V0/V1与选定候选离线通过；涉及生产控制或设备操作时依赖用户恢复对应授权。纯接口模拟可提前开展。接入现有唯一相机服务，算法不得新增设备控制owner、重复打开相机或接管串口。

初赛单件过程尽早验证：粗停→机构观察姿态→新观测→已验收工作窗口/修正→抓取→存车→短运输→取出→放置→退出→真实结果确认。具体控制实现沿用整机方案P0/P1，不为了视觉实验绕过其中停止和交接缺陷。

对位策略按工位与本次任务版本冻结。L0使用已证实工作窗口；L1底盘微调尚未通过则禁用；L2伸缩+整臂旋转另行几何验证，不能运行中无条件切换。每次修正后重新停稳并获取新帧，有限次数/距离/时间到限后输出失败或未知，不无限追像素。

| 关口 | 最低交付与通过条件 |
| --- | --- |
| G0 基线 | 样本/版本/已有失败真实可追溯 |
| G1 离线候选 | 独立集收益、负例、覆盖率和耗时；默认基线可回退 |

Pi并发验收沿用已定目标：每个实际启用模式至少60秒记录P50/P95/max、源帧龄、过期拒绝、吞吐、CPU/内存/温度/降频；有效帧仍须≤250ms。处理P95≤100ms和完整有效观测争取≥8Hz为待实测工程目标，不是现有保证；不能放宽保护来达标。不要在Pi无预算地双跑新旧全管线，优先离线回放，同机影子模式也要测负载。

## 六个工作日的推进安排

日期按现场资源调整，依赖与实物关口不能按日历自动跳过。比赛11月6日，争取11月4日完成冻结，11月5日留复核缓冲。设备暂停时继续离线工作，不把日历当设备授权。

| 工作日 | 核心任务 | 完成标志 |
| --- | --- | --- |
| D1 | V0/V1；同时准备V2三类诊断，获准后现场采集 | 基线、缺项、初筛结果或明确待测原因 |
| D2 | 按证据选首要瓶颈；接口模拟；条件具备时尽早单件联调 | 一个可解释的小改动或执行问题定位 |
| D3～D4 | 候选逐项验证/集成，每次复测单件；扩展三槽三环两批 | 候选收益与整机结果关联，失败可定位 |
| D5 | 连续任务、负载、不同光照、冷启动与异常恢复 | 完整流程证据和冻结清单 |
| D6 | 只修阻断、回归与缓冲 | 比赛版、回滚包、现场操作清单及已知限制 |

圆心、QDA、二维码是条件分支，不是必须全部完成。若已有视觉足够而执行未通过，资源优先投入执行问题；若缺数据，交付可用工具和明确的采样请求，不伪造确定性。
