# 两轮视觉方案评审

日期：2026年10月30日。依据：用户提供的《视觉.txt》《视觉改.txt》、源码基线6f8694f、现有现场记录及本地合成实验。本文记录裁决和证据；[开发方案](vision_development_plan_20261030.md)规定后续实施方式。

## 结论

保留传统OpenCV主线，先固定观察条件、建立真实尺度与独立评价，同时定位机构重复性和执行问题。相机标定、圆心精修、颜色分类及二维码候选按失败证据选用。离线研究可以并行，主线集成逐项验证；完整单件循环尽早进入联调，不等到最后一天。

新版精修器相比旧版实质改善了空白和遮挡输入的处理，可作为局部精修候选，但尚未通过实车精度、完整场景和Pi性能验收。不能把整个附件当作已经可执行的生产实现。

## 现状纠正

| 原判断 | 经核对的结论 |
| --- | --- |
| 四路识别约45ms | 45.220ms是特定静止场景圆环检测中位数；不是四路总耗时或整机周期 |
| 所有模块共用5帧500ms | TaskLatch至少3个不同新帧、跨越100ms；各模块确认策略不同 |
| 中心只有bbox，没有拟合 | 圆环已有fitEllipse；物料矩心为浮点数，但浮点输出不证明定位精度 |
| 自动对中代码锁死 | physical_directions_checked、相机及姿态绑定等准入条件尚未满足 |
| 历史47.57px/8mm证明缺手眼 | 夹爪姿态、物料位置、接触等因素混在记录中，不能单因归因 |
| 二维码没有可靠校验 | 已有格式校验、去重冲突拒绝、时效与锁存；改解码器须保留 |
| 增加冲突拒绝是新工作 | 评审回复在此表述不清；TaskLatch已经返回AMBIGUOUS，属于保留现有能力 |
| 0.4mm/px可用于车上预算 | 原文是条件假设，双方均不应将其当作本车实测尺度 |

原文缩放算式应为0.5处理像素×1280/480×0.4mm/源像素≈0.53mm，非0.2mm。φ+3带来的1.5mm理想径向余量不等于视觉独占预算，也不替代实际规则、物料形状及释放后落点验收。

## 标定与误差链

内参和畸变描述相机成像；H描述固定观察条件下的像素到某个平面；运动Jacobian描述执行指令引起的图像变化。H不能替代底盘方向、尺度、横移耦合和重复性验收。原料顶面、地面圆环、码垛顶面分别建模；相机随机构移动时不能无条件沿用旧H。

findHomography(image_pts, world_mm_pts, RANSAC, 2.0)的残差阈值是目标坐标单位，此处为2mm。RANSAC阈值只是拟合内点选择条件，不是最终真实误差上限；不能把它直接当作误差预算已消耗多少。四点拟合之外必须有独立检查点；单个已知直径不是完整任意H的充分输入。

完整手眼标定需要已知机械末端姿态和对应视觉姿态；一般求解需要非平行旋转轴的运动。当前尚未确认足够的运动可观测性、实际舵机角度和刚性相机安装关系。固定姿态局部抓放对应可以先服务比赛，无需先完成通用六自由度标定。

最终误差经过识别、几何对应、执行、机械重复性、夹持与释放。+Y实物失败仍是执行限制。平均系统偏差、随机散布、载荷影响、方向回差和释放偏移应分开量测；不能把各项标准差直接相加或未经独立性证明按平方和开根号计算总误差。

这些测试证明改进与限制，不能证明真实精度。附件中其他遮挡角度、三层环数据未在本次完整复现，不能记为本项目验收。

新版尚有以下问题：

- 极坐标图列为半径、行为角度，GaussianBlur的(1,3)沿角度平滑，与“沿半径”注释相反；如果设计就是角向平滑，应修正注释并验证角度周期边界，否则实现径向平滑后重测。
- 二倍角项可吸收部分形状变化，但一倍角系数直接作为中心偏移仍是近似；拟合残差小不等于几何中心准确，更不等于物理圆心准确。
- 总覆盖率不能替代角度分布、拟合条件数和模型有效性。需要对局部遮挡、裁切、相邻环、数字笔画和其他暗边缘测试。
- argmin落在边界后idx被clip，val与b可能来自不同位置；应明确拒绝边界候选并让插值、暗度、位置使用同一极值点。
- 应检查图像类型、有限数、n_ang、半径范围、搜索带宽度、极坐标映射的原图有效域；不能让图外填充值形成假暗环。
- 只返回坐标或None不利于验收；候选接口需输出覆盖率、残差、有效角度、修正量和失败原因。
- 不能固定套用“半径偏置2px”或“半径误差绝不影响中心”。常数径向偏移与角度相关、遮挡相关误差不同。

采用方式为粗检测可信候选→单层ROI精修→模型及质量校验→按冻结策略接受、回退粗结果或拒绝。失败策略按工位统一，不能自动选看起来更接近目标的输出。

## 颜色与二维码裁决

完整QDA最小化d²+ln|Σ|-2lnπ。旧附件只有马氏距离，不等价。8个三维样本不必然奇异或病态，但小样本协方差估计不稳；还须区分“8个颜色代表点”和原始独立采样数据。Ledoit–Wolf、OAS、固定收缩或对角模型均需独立集对比，不预设某方法必胜。保留UNKNOWN、绝对质量和类别间隔，不强制六选一；白色过曝区域不能靠协方差恢复已丢失的颜色信息。

TaskLatch已有冲突与时效检查不表示解码器一定是故障唯一来源。先分类曝光、距离、裁切、模糊、过期和真实解码失败；必要时用候选解码器做有期限的后备，不在串口线程执行。WeChatQRCode有检测和超分两个CNN及四个模型文件；依赖、包冲突、Pi耗时均需实测，不能沿用“只需一行pip、20～40ms”的承诺。

## 其他建议裁决

| 建议 | 决策 |
| --- | --- |
| Kalman替换稳定窗 | 不采纳。预测不算新观测，平滑不能代替时效和停稳证据 |
| 全图480升到640 | 候选，像素量约1.78倍；优先比较源图ROI精修和整图提升的实际收益与耗时 |
| 同心圆恢复透视 | 理论方向可研究，当前不是比赛关键路径；不能声称偏差归零 |
| HOG/SVM或小CNN | 实际错号成为瓶颈后才开启独立分支，不承诺200张够用或Pi低于2ms |
| 补光加偏振 | 配对实验，不接受“唯一改善六色”或“十倍”。曝光、白平衡和拍摄角度也需比较 |
| 20张对照图 | 可以初筛，不足以证明全场可靠性；需覆盖各色和独立拍摄条件 |
| 钢尺10次确定0.1mm预算 | 不成立。记录测量不确定度，工具能力不足时只报告毫米级初筛 |
| 一天三项诊断 | 可并行准备，现场实测须在授权恢复后开展；不保证半天查明全部根因 |
| 三项诊断直接走现有replay | 现有脚本是历史迁移一致性比较，须新增候选/真值评价能力；不是已有完整测量工具 |
| 六天逐日精修、QDA、二维码 | 改为按证据选分支，不将全部升级列必做；尽早单件联调 |
