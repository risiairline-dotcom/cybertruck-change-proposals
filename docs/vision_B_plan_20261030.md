# 电脑B视觉优化任务（2026-10-30）

## 决策与依据

三天冲刺保留现有OpenCV：Lab颜色统计+HSV过滤/轮廓、圆环几何+旋转数字模板、OpenCV二维码。暂不加入YOLO、训练框架或新硬件，不改运行环境。已有实现适配固定比赛目标，具备旧样本和当前Pi性能证据；尚不能宣称满足整场比赛。

docs/ring_latency_20261029.md：同图旧检测约142ms，新约45ms，结果相等；静止场景60.328秒184次请求有效，最大帧龄207.204ms。此证据不覆盖全场精度、复杂光照或动态闭环。docs/vision_preview_20261028.md：请求30FPS但实测采集约14.8FPS，预览速率、采集速率、检测速率分开。

当前查阅源码/上述记录未确认Pi具体型号、RAM、散热或AI加速器，不套用Pi5公开基准预测本机性能。恢复连接后由A采集硬件信息及CPU/温度/降频/内存和并发运行数据，B据真实目标机结果优化。

官方参考：https://docs.ultralytics.com/guides/raspberry-pi （ARM部署/NCNN与目标机基准）；https://docs.ultralytics.com/modes/train （自定义数据训练）。YOLO可在Pi运行，但比赛六色物料和印刷环号尚无本项目已训练验收权重；更换需标注、训练、独立验证及端侧部署。检测框本身不证明持料/释放，也不提供已验证的机械几何映射。

## B负责范围和第一优先级

沿用codex/vision-mission分支、Git共同基线；以远程最新main及docs/dual_pc_handoff_20261029.md为准。旧ZIP仅提供离线样本。B负责纯视觉算法、独立确认模块/测试、任务证据适配。底盘+Y仍实物未通过；不批准自动对中，不修改centering/arrival、控制器或固件。

1. 先统计所有样本的人工标签、拍摄场景、观察姿态、来源和可用性。没有真值的只列待标注，不拿算法输出作真值；同一次视频/连拍划为同组，不把邻帧拆到调参集和验收集。
2. 建立固定回放报告：六色混淆矩阵、漏检/误检/拒识数，圆环1/2/3错号/漏号/裁切，QR合法/非法/读不到，按光照、姿态、遮挡分层报告。小样本必须给分子分母，不只给百分比。
3. 只针对已复现失败改Lab/HSV、ROI/形状、黑色与阴影、蓝/浅蓝混淆或数字提取；保留旧实现负对照/回归图，不能为提高命中率盲降拒识阈值。先提交基线报告再优化。
4. 图像输入只用唯一相机服务最新帧，保留frame_id、采集身份、配置SHA、分辨率和观察姿态；不另开相机或串口。不积压待识别帧，不让JPEG编码/Web预览阻塞执行线程。
5. 连续确认只计不同且新鲜的帧；沿用当前已建立的稳定窗，停稳/观察姿态变化后清空旧窗。短暂丢目标先保持停车并在有限窗口重观测；不得用旧框继续运动或重发已接受动作。B提供视觉状态，A实现运动策略。
6. 持料、存车、释放各自需要对应观察位和前后证据；保留UNKNOWN。没检测到不等于空爪，命令完成不等于抓取成功。先输出候选ROI、所需样本和离线测试，再等实物验收。

## 样本一次性采集清单（A组织，用户只摆放/验收）

- 六色：各色单件及三件混放，正常光/阴影/反光，蓝与浅蓝重点；黑色背景干扰和空台/夹爪线缆负例。
- 圆环：1/2/3完整、偏视、部分遮挡、画面边缘；粗加工与暂存各自标明目标平面。标出真实号和可见中心；不可判断的保留未知。
- 二维码：现场实际任务码、不同距离/角度，模糊、截断、非法任务码和无二维码。
- 实际动作：空爪观察、夹住未抬、抬起稳定、空抓/打滑、槽位空/已存、落地但未松/松开退出。按可见性设计确认姿态，不假定所有阶段都看得见。
- 固定曝光/白平衡先检查设备能力和低光拖帧、频闪；禁止盲锁相机参数。改变参数/ROI/分辨率必须新配置版本，由A决定是否重验标定。

先复用已有样本。B把真实缺项汇总一张清单交A，避免让用户重复采同一场景。正式台更换后补相关高度与观察位样本。

## 验收目标（是目标，不是已通过）

- 每项报告独立验收集规模、正确/错误/未知及典型失败图；六色/环号/QR的已接受结果正确率目标>=99%，已接受错色或错号一例就必须解释修复或收紧适用范围。目标不是统计置信保证；漏检和UNKNOWN另计，不能靠全部拒识达标。
- 现场每个目标类别至少3次独立摆放/观察，三种槽位和三环分别覆盖；最终端到端连续三轮任务通过，三次不等于可靠性证明。
- Pi实际并发相机/任务/设备反馈下，每个启用模式连续60秒测源帧龄、处理耗时P50/P95/max、不同帧吞吐、错误数、CPU/内存/温度。有效帧必须仍<=250ms；记录真实拒绝，不能用PC性能代替。处理P95暂以<=100ms作为工程目标，完整有效观测争取>=8Hz，依据整机负载调整算法而非放宽反馈保护。
- 不追求30FPS全模式同时识别：扫码只在扫码阶段，物料在选料/确认阶段，圆环在停靠阶段；预览独立限流。所有模式都保留正确坐标映射和同帧证据。
- 视觉只输出任务所需结果，task/ledger仅在对应实物确认后提交成功事件，重复结果不重复计数。
